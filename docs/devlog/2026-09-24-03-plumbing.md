# 03. Plumbing that was quietly wrong

2026-09-24.

## Context

With the model matching PyTorch, differences on real files pointed at
everything around it.

## What was done and what was found

- **MP3 decode clamped samples to [-1, 1]** in Symphonia 0.5. Real
  masters exceed full scale after decoding; the clamp changed the input
  before the model saw it. Moved to Symphonia 0.6, which does not clamp,
  with explicit codec features.
- **FLAC output was read as variable-block-size** by some readers:
  the encoder wrote the last partial block's size as the STREAMINFO
  minimum block size. The writer now patches min = max.
- **Resampling delay**: measured with impulses rather than assumed.
  rubato's windowed sinc in 4096-frame chunks with a flushed tail is
  time-aligned; no trim needed.
- **Memory**: the in-graph export made ONNX Runtime's constant folding
  materialize 3.8 GB of STFT index tensors at load. Turning folding and
  the memory pattern off took peak RSS from 5.58 GB to 2.12 GB for 11%
  throughput. fp16 weights changed nothing.
- 24-bit WAV and FLAC output added.

## Decision

Every fix got a test or a recorded measurement. Nothing was changed on
the grounds that "it should be fine".
